# M4b Yearly 视图 实现计划

> 控制器直实现,逐任务 TDD + 验证 + 独立提交。Phase 2 增量。

**Goal:** 放开 `yearly`(365 天窗口)周期:评分作业物化 yearly 榜,API(trending/languages/developers)接受 `period=yearly`,前端周期切换加「年」。

**Architecture:** 评分引擎已按 `Config.PeriodDays` 支持任意窗口——只需给 `DefaultConfig` 加 `yearly:365`(RunScoring 自动物化)。API 的 `validPeriods` 加 `yearly`。前端 `Period` 类型 + `PeriodTabs` 加 yearly。

> **依赖:** M0–M4a 在 `main`。`scoring.DefaultConfig().PeriodDays`、`api.validPeriods`(trending.go,被 trending/languages/developers 共用)、前端 `PeriodTabs`/`Period`。
> **注:** RunScoring 的 maxWindow 变 365 → 每日加载约 729 天增量重算所有周期(yearly 日变化小,重算略浪费但正确;成热点再优化,例如 yearly 降频)。
