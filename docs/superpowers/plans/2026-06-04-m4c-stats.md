# M4c Insights/Stats 实现计划

> 控制器直实现,逐任务 TDD + 验证 + 独立提交。Phase 2 增量。

**Goal:** 站点级聚合:`GET /api/v1/stats`(活跃仓库数、快照总数、语言数、话题数、开发者数、最新榜日期、最近采集时间)+ 前端 `/stats` 页。

**Architecture:** store 新增 `Stats()`(复用 `HealthInfo`/`CountDevelopers`/`LatestRankingDate` + 几条 COUNT)。api 加只读端点。前端加页面/导航。

> **依赖:** M0–M4b 在 `main`。已有 `HealthInfo`、`CountDevelopers`、`LatestRankingDate`、api 约定、前端 client/路由。

---

## Task 1: store — Stats 聚合

**Files:** `internal/store/stats.go`、`internal/store/stats_test.go`

```go
type Stats struct {
	ActiveRepos       int
	TotalSnapshots    int
	Languages         int
	Topics            int
	Developers        int    // daily 榜上的不同 owner 数
	LatestRankingDate string
	LastSyncedAt      string
}
```
`Stats()`:复用 `HealthInfo()`(ActiveRepos+LastSyncedAt)、`CountDevelopers("daily")`、`LatestRankingDate("daily")`;内联 `COUNT(*) repository_snapshots`、`COUNT(DISTINCT language) repositories(is_active=1, 非空)`、`COUNT(DISTINCT topic_id) repository_topics`。

测试:seed 仓库+快照+语言+话题+日榜,断言各计数与最新日期。
