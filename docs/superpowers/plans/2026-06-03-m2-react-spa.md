# M2 React SPA 前端 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 或 executing-plans。本计划因 subagent 基础设施不稳,默认由控制器直实现,但仍逐任务 TDD + 验证 + 独立提交。Steps 用 `- [ ]` 跟踪。

**Goal:** 一个 Vite + React + TypeScript + Tailwind 的客户端渲染 SPA,消费已完成的 `/api/v1/*` 读取 API:首页/各期趋势榜(日/周/月切换 + 语言筛选)、仓库详情(star 曲线 + 历史排名)、搜索。构建产物由 Go API Server 经 `go:embed` 一并托管(单部署单元,非 API 路径回退 `index.html`)。**无 SSR/SEO**。

**Architecture:** 新增 `web/`(Vite SPA)。Go 侧新增一个静态资源 handler:把 `web/dist` 用 `go:embed` 打进二进制,在 `internal/api` 里挂为兜底路由——`/api/*` 与 `/healthz` 仍走 JSON handler,其余路径 serve 静态文件,找不到文件则回退 `index.html`(交给前端 react-router)。前端用一个 typed fetch 封装调 API,react-router 做客户端路由,recharts(或等价轻量库)画 star 曲线,Tailwind 做样式。

**Tech Stack:** Vite · React 18 · TypeScript · Tailwind CSS · react-router-dom · recharts · Vitest + @testing-library/react + jsdom。Go 侧:`embed` 标准库。

> **依赖:** M0/M1a/M1b 已在 `main`,REST API 7 端点可用。Node 26 / npm 11 可用。**`npm install` 需要网络**(一次性,类比 `go get`)。Go 构建仍 `GOPROXY=off`。
> **DTO 契约(前端类型据此):** `/api/v1/trending` → `{period,date,page,per_page,total,items:[{rank,score,star_delta,repository:{id,full_name,owner,name,description,language,stars,html_url,owner_avatar}}]}`;`/api/v1/languages` → `[{language,count}]`;`/api/v1/repositories/{id}` → `{id,full_name,owner,name,description,language,homepage,html_url,owner_avatar,stars,forks,open_issues,watchers,repo_created_at,best_daily_rank|null}`;`/{id}/snapshots` → `{repository_id,snapshots:[{date,stars,forks,open_issues,watchers,star_delta}]}`;`/{id}/rankings` → `{repository_id,rankings:[{period,date,rank,score,star_delta}]}`;`/api/v1/search` → `{query,page,per_page,total,items:[repository]}`。

- [ ] **Step 3: 实现静态托管**

`internal/api/static.go`:
```go
package api

import (
	"embed"
	"io/fs"
	"net/http"
	"strings"
)

//go:embed all:dist
var distFS embed.FS

// staticHandler 返回托管嵌入的前端构建的 handler:
// 命中真实文件则直接返回;否则(且非 /api、非 /healthz)回退 index.html 交给前端路由。
func staticHandler() http.Handler {
	sub, err := fs.Sub(distFS, "dist")
	if err != nil {
		panic(err)
	}
	fileServer := http.FileServer(http.FS(sub))
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		p := strings.TrimPrefix(r.URL.Path, "/")
		if p == "" {
			p = "index.html"
		}
		if f, err := sub.Open(p); err == nil {
			f.Close()
			fileServer.ServeHTTP(w, r)
			return
		}
		// SPA 回退:非文件路径返回 index.html
		r2 := r.Clone(r.Context())
		r2.URL.Path = "/"
		fileServer.ServeHTTP(w, r2)
	})
}
```

- [ ] **Step 4: 在 Routes() 挂兜底**

在 `internal/api/server.go` 的 `Routes()` 里,所有具体路由之后、`return mux` 前加:
```go
	mux.Handle("/", staticHandler())
```
(Go 1.22 ServeMux:`/` 是最不具体的模式,只在没有更具体路由命中时兜底;`/api/v1/*`、`/healthz` 仍优先命中各自 handler。未注册的 `/api/...` 路径会落到 `/` 兜底——为避免把它当 SPA,staticHandler 对 `/api/` 前缀直接 404。)

补充:在 `staticHandler` 的 HandlerFunc 开头加:
```go
		if strings.HasPrefix(r.URL.Path, "/api/") || r.URL.Path == "/healthz" {
			http.NotFound(w, r)
			return
		}
```
